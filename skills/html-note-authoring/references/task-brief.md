# 制作底稿与按任务条款

本文件是 Skill 自带的制作底稿与按任务条款，供仓库内外的制作任务直接使用；库内路径按实际库根理解，接口与资料通过查询 CLI 按需读取。

派发时替换占位项、删除无关条款，直接完成作品；不要求先提交另一份任务文档，也不在末尾追加补丁。

## 通用制作底稿

```text
你负责制作指定知识的 HTML 可视化。以本次内容和操作范围为准，交付可阅读、可回顾的成果。

一、本次演示主题

<粘贴对应 MD 预留或简要需求：要解释的问题、表达对象或过程、理解目标及必要边界。已有明确的展示意图一并保留。>

二、执行上下文与范围

- 源 MD：<实际文件路径>
- 对应位置：<标题、预留编号或明确范围>
- 组件库：<实际可用目录>
- 制作与输出位置：<实际目录和必要文件名>
- 允许改动范围：<源 MD、参考资料、组件库和输出目录分别怎样处理>
- 交付形式：<例如独立离线 HTML，并保留必要作者源文件和重新生成方式>
- 本次专属要求：<仅在需要时填写，例如固定参数的阶段试用、明确要覆盖的公共能力、或与既有作品比较的范围>

执行 Agent 是作者：要理解的目标、知识重点、观察关系与表达方式由你根据材料判断，任务模板与组件库不自动推断。先理解本次材料中相关内容，补读必要上下文。核对知识、单位、规则和适用条件；示意、省略和比例简化清楚说明。开始观看所需的对象与记号应容易识别，无须复制整章 MD。

三、表达与阅读要求

沿用本 Skill 的阅读与演示共识（见 `references/principles.md`），优先保证：

- 演示是视觉中心；必要前提、对象/数值/单位标注与解释沿正常阅读路径组织，结果读数与状态记录集中；本步变化及意义由稳定字幕解释，字段组成与推导归正文。
- 步骤按有独立理解价值的稳定状态划分，一次推进可包含配合动作；完成后保留依据和结果，支持回退/重看；字幕与图形允许先后阅读，同一停点内不按计时连续替换多句。
- 主要变化有主次和承接；对象运动、对齐窗口等自然引导已能对应依据与结果时不必叠公共 Focus 框，只有跨区域依据/结果无法直接对应、主要变化需要寻找时才用。视图变化须列入 scene.bindings；阶段/模式/目标参数摘要可随提交，已收到/已完成事实随领域事件或实际展示进度；提交方式 update/cut 按事实与视觉需要，是否 Focus 巡视另判，不要求一律 cut/巡视/数字动画。
- 读数按语义更新：阶段/模式/目标参数可随提交；"已收到/已发出/已完成"必须随领域事件或实际展示进度；预期值可提前显示但要标明目标/预期。
- 画面、解说和基本控制便于一起查看，推进不推挤操作区；必要文字正常可读，不用缩小字号、角落小字、悬停或折叠隐藏解决解释拥挤。
- 用对齐、留白、比例和视觉层级形成完成度，具体图形随知识适配；不固定所有作品的步骤数、句数、颜色、时长或页面比例。

先确定本步理解目标和主要阅读顺序，不要求页面固定设置四个区域。布局后检查是否跨多处拼接解释、重复讲述同一道理、当前必要条件被藏走。

静态图解和参数联动按各自观察目标组织，不为凑齐步骤、字幕、控制或焦点而增加无意义结构。交互默认服务于观察、推进和回顾，不自行增加测验、评分或闯关内容。

四、实现与取用

已有有效上下文直接沿用，缺什么补什么。先 `show authoring:start` 取通用路径选择，再按需 `show`/`read` 单条；未知能力先 `search`，不要求先通读全部资产清单和公共层手册。

复用公共组件、布局和运行能力；多停点/回退/attention 使用现有 NoteDemo，使用前核对当前接口和边界。调用真实接口，不凭名称猜参数，不复制播放器或用硬编码等待模拟公共完成机制。

领域模型决定知识状态与计算，注意编排不改变模型中的时间、因果或并行关系。无合适组件时在允许范围内局部实现并说明真实缺口，不静默省略或擅自扩大共享库开发。

五、必要核对与交付

核对知识模型和代表状态，以实际速度观察需要动态理解的过程；有具体疑点再补针对性探针，局部修改只复核相关影响。确认交付文件能按约定打开、资源完整、关键操作正常；有动效时减少动效仍应呈现正确且可理解的状态。

不默认做逐对象像素断言、全数值遍历、全视口截图或组件库完整回归；共享实现有改动时按实际影响扩大验证。回复链接实际成果，简述表达、复用、验证与剩余限制，区分程序检查与实际观察，不另建报告、状态文档或测试流水。
```

## 按任务需要补充的条款

只加入本次需要的部分；具体参数、知识内容与权限并入底稿相应章节。

| 情况 | 应补充什么 |
| --- | --- |
| 新 Agent 冷启动 | 交代当前工程位置、有效入口、已有成果和本次范围；旧任务不自动成为新授权 |
| 复用同一制作 Agent | 说明新任务与上一作品的关系、保留哪些成果、输出到哪里；不强制重新通读同一批文档 |
| 参数联动 | 指出可改变的量、需观察的关系和领域范围；数值、说明与图形读取一致状态，连续操作不积累迟到变化 |
| 过程或规则演示 | 指出关键事件、触发条件与理解目标，让作者划分有意义的停点；不把示例时刻数量规定为固定点击数 |
| 明确测试公共聚焦 | 写清要验证实际到达、内容启动、可承接后交接及最终收束；单独画一个框不等同于覆盖公共协调；接口细节查当前 API |
| 局部调整已有作品 | 给出具体问题与需保持的行为，修改和复核围绕影响范围，不重新设计整页或重复整套验证 |
| 限定权限或特殊试验 | 写明对象、动作、适用阶段和结束条件，避免被后续任务机械继承 |

已有演示可供参考时，说明需要借鉴的具体表达或接口。参考某个局部不代表整页布局、主题、数据与时长全部适用。
