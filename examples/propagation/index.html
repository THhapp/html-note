传播过程与局部过渡

一个自定义 SVG 图形只暴露一个 Binding：attention 只指向本步真实运动对象（发送前沿、B 命中事件点、回传前沿）， 不重复巡视基站；连续 next 从上一停点的弱化位置直接承接。EffectSpec type:'progress' 连续驱动 SVG 带宽与前沿位置， 文字标签与图形同属一个效果组，handoff:'hold' 让局部淡入的末帧保持到收束。每步内容约 0.9s，给辨认时间， 但只覆盖本示例的 scene。每个停点只追加自己的历史证据层，不整图重建、不叠画重复信号带。

画面默认静止；请用演示下方控件推进。一次“下一步”只增加一个理解停点：看前沿走到哪、事件出现在哪； 焦点从上一停稳位置承接，不重新巡视。运行中可取消，重看/重来不会叠加历史层；系统开启减少动效时直接落到目标停点。

同一 Binding 的局部交接

连续 next 时，上一停点的弱化焦点直接承接为下一步起点；T2 的新前沿从同位置启动， 再用两个内容目标分别放行 lead 与 event 两个局部组；同一组只被一个目标门控，不重复启动。

前沿与范围连续展开

发送段/回传段的 x、width 与前沿圆点的 cx 由 progress 句柄逐帧更新， 位置连续；取消后不再回调，不会残留中间几何。

文字与图形同组

事件标签和历史刻度都带 spec.group，与对应图形同组启动、同组 ready； 局部淡入声明 handoff:'hold'，完成后保持末帧到 scene 收束；未放行的组保持来源视觉（带宽 0、标签隐藏）。

历史证据分层

每个停点只追加自己的 .pg-layer（发送段、命中事件、回传段），历史层保留且互不覆盖； 焦点始终跟随真实运动对象；观察区域用公共 `NoteDemo.effects.unionRange` 组合移动前沿、轨迹条与标签，随 band 增长连续包住变化段，不框整图或整条轴。 

var session = NoteDemo.mount(host, {
  definition: PropagationDemo.definition,
  layout: PropagationDemo.layout,
  adapters: { 'propagation-graph': PropagationAdapter }
});
