NOTE VIZ · FLOW KIT

独立图形模块中性演示

四个图形各自 mount、各自 update、各自 getTarget，不依赖其他 NoteViz 组件，也不含课程规则或自动播放器。 稳定 ID 来自宿主数据；更新按 ID 复用 DOM。DeviceLinks 额外提供 link path 与 pointAt，供宿主做传播采样。

StageTrack · 阶段轨

当前/完成/跳过/失败状态由宿主给出；旁路是显式 from → to 端点，不会自动推断。

PacketFlow · 消息流

参与者与消息都有稳定 ID；方向由参与者顺序决定，逐步显现只读宿主给的 visibleCount / revealed，不嵌套播放器。

SegmentBar · 段条

真实值、显示尺度（scaleMax）与最小可读宽度分离；零长度仍显示为最小宽度标记，但 data-real-value 保持 0。

DeviceLinks · 设备连接

设备和命名端口、连接都有稳定 ID；状态由宿主给出。连接可查询 SVG path，并用 pointAt 采样路径上的点。

源码：src/viz/flow.js + src/viz/flow.css；本页只是中性演示，不依赖未集的 manifest，也不写课程规则。
