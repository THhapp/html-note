画面默认静止；请使用演示下方控件推进。离线单文件与开发入口使用同一份作者入口（整库 JS/CSS）。

末步按钮禁用不等于正在运行。“下一步”禁用只表示没有下一停点；“上一步/重看”在运行中还可取消当前步骤。需要判断是否运行时，读 session.getState().phase（idle / running / error / disposed）；本页状态文字由 boot.js 的 subscribe 写出，未新增播放器或公共 API。默认舞台控制容器上的 data-demo-running / aria-busy 只用于样式与读屏提示，同样不代替 phase 判断。

观察目标与内容目标分开：groups: [] 只观察、不启动内容；省略 groups 时按整个 Binding 在真实到达后启动（当前内置 Adapter 未细分效果组）。holdDuration 对观察目标是停留时长，对内容目标是 ready 后的额外等待，0 是有效值；最后落点不加倒计时。

普通 DOM 交接使用自定义 Adapter（handoff-demo.js）。commit 隐藏来源标签、预置目标标签 opacity 0；PreparedChange.sourceElements() 让来源标签在观察期保持可见，直到本步第一个内容效果轨道启动才释放；目标标签的 WAAPI 淡入声明 handoff:'hold'，结束后末帧保持到 scene 收束，避免先回落到预置隐藏值再等清理。自定义 Adapter 只使用公开契约（Definition / Adapter / PreparedChange / EffectSpec / scene.attention），不读取 NoteDemoInternals。

完整 Definition 仍是高级入口；例如可将 demo.definition 交给 NoteDemo.create 或保存后检查。字幕和操作位置由公共舞台维护。
