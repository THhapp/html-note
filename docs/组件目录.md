# 组件目录

本页是按类别定位组件的单一人读入口。机器清单以 [registry.json](../registry.json)（由 `src/manifests` 与 `src/status.json` 构建）为准；接口、依赖、限制、技术状态与用户评价范围见 registry 条目及各模块文档，本页只做定位，不复制这些字段。

当前 **101 条、17 个分发模块**：84 项组件能力（R01–R10 复用 10 项＋新增 74 项）、10 项组合块（B01–B10）、7 项共享基础（I01–I07）。变体、预览、示例与分发副本不重复计数；R01–R10 沿用旧公开名。

入口：[取用与组合](取用与组合.md) · [库入口](../README.md) · [单文件预览](../dist/组件库-预览.html) · [registry](../registry.json)。查看单项：`examples/run.html?id=<ID>` 或 `gallery/index.html#<ID>`。

## 维护说明

- registry 是唯一机器清单；新增、改名、改类别或改依赖时只改 `src/manifests`，再重建 registry，本页不另建状态表或接口表。
- 文档列优先使用模块文档中的显式 `<a id="…">` 锚点；无显式锚点时用标题的 GitHub slug，标题可能随模块文档调整时退回文件链接（如构建与分发、公共编排层）。
- 本页只同步受影响行的 ID、公开名、所属模块、文档锚点与一句用途；完整参数、事件、限制和状态仍查 registry 与模块文档。
- 分发按模块进行，不按条目 tree-shaking；同模块内其他条目也会随模块一起加载。依赖顺序见[取用与组合](取用与组合.md)与[构建与分发](构建与分发.md)。
