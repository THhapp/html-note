# 查询语料

本文件是 `scripts/query.mjs` 直接读取的作者检索元数据，记录资产的用途、适用边界和取用入口；不是完整资产清单，也不是另一套 API 手册。Q 编号只用于本文件讨论，不替代既有组件 ID。

这些资料描述“已有资产能做什么、适合什么、去哪里取用”。知识理解、表达选择和领域模型仍由作者 Agent 负责；不建立按课程主题自动生成演示方案的案例库。

<a id="corpus-usage"></a>

## 怎样使用

查询入口与阅读分工见[取用与组合](取用与组合.md#reading-map)；任务输入与 Skill 继承关系见[提示词撰写](提示词撰写.md#skill-content-inheritance)。资料怎样形成搜索结果、取用包和定向读取，见[查询 CLI](查询CLI.md)。

| 要查什么 | 范围 | 接下来读取 |
| --- | --- | --- |
| 视觉基础和文字、布局 | Q01–Q03 | 设计值、具体组件的用法；视觉原则查设计共识 |
| 公式、读数、表达式与参数 | Q04–Q07 | 独立组件 API；需要过程过渡时再查公共接入 |
| 序列、矩阵、标记与插入机制 | Q08–Q13 | 能力区别和限制，再取独立调用或 scene 用法 |
| 舞台、字段组合与作者配方 | Q14–Q16 | 组合提供的部分、作者责任及适合结构的示例 |
| 会话、连续变化、聚焦、交接与作者简写 | Q17–Q21 | 对应公开契约，不默认通读全部公共层手册 |
| 分文件制作与单文件交付 | Q22 | 模板与内联器使用方式 |
| 扩充图形、边/表状态与 scene 接入 | Q25–Q39 | 独立图形、稳定 target、Adapter canonical model 与变化组 |
| 流程组合、传播与配方 | Q40–Q42 | 完整组合示例、路径传播机制与区域/步骤配方 |
| 本地观察与最小连续画面示例 | Q23–Q24 | 验证入口、依赖边界与可提取接法 |

不知道名称时先按用途检索；知道 ID 或公开名称时可直接取对应 API。阅读每条的“用途”和“适用与边界”后，再选择需要的后续入口；独立调用和公共接入分开取用。无匹配时继续查完整组件目录，不能仅据本文件未命中就认定库缺少能力。

例如，要让自定义图形沿时间变化，可先取 Q18，再按需要补 Q19 聚焦协调或 Q20 内容交接。要排列字节，先取 Q08；确定还要现成的单点插入机制时再比较 Q13。具体表达和组合由作者判断，不要求每次沿同一条链读取。

## 结构化字段

CLI 在查询时直接解析本文件的 `### Qxx` 记录，不维护第二份语料 JSON：

- 组件记录用“类型／关联”中的第一个既有 ID 关联 `src/manifests`；不得另造组件 ID。`检索词` 提供中英文叫法，`用途`、`适用与边界`、`关联`、`后续读取` 提供选择资料。
- 配方、公共接法、作者辅助和构建工具有独立 `条目 ID` 与 `展示名`，不计入 101 个组件；`调用上下文`、`最小用法`、`依赖`、`资料角色`、`资源` 描述实际取用方式。
- 主题记录用三个稳定结构化字段，CLI 只解析这些字段，不从 `依赖` 自由文本猜模块：
  - `模块依赖：module[, module...]`：浏览器组件模块名；`none` 表示无浏览器模块（工具）。CLI 沿 `src/manifests` 计算多模块闭包，按发布顺序 `MODULE_ORDER` 合并输出。
  - `运行入口：independent|scene|public|recipe|authoring|example|tool`：决定 `show` 的 context key；`example` 目前映射到 authoring（完整示例没有独立 example context，查询时用 `--context authoring`）。
  - `区域组件依赖：caller` 或 `region=module[；region=module...]`：仅配方使用。配方骨架依赖仍写在 `模块依赖`；区域组件模块按调用方实际 bindings 另加，不并入骨架闭包。
- 需要公共 scene 接入的组件可补 `场景支持：mode=...；默认=...；说明=...`，CLI 直接把这份声明用于该上下文；没有该声明的 Adapter 明确显示“支持范围未确认”，不套用全模式骨架。
- `资源` 路径从工程根解析，格式为 `api=docs/...#锚点; guide=...; source=...; example=...; fragment=...; full=...; minimal=...; control=...`。`api` 是完整 API/契约，`guide` 是直接接入参考，`example` 是该条目的示例入口，`full` 是完整示例，`minimal` 是最小可运行宿主，`fragment` 是局部接入片段，`source` 是实现源码，`control` 是受控视觉接管说明，不能混称。正文仍由现行文档、源码和 examples 维护，不复制进本文件。
- `后续读取` 的 Markdown 链接相对 `docs/` 解析；新增或修改记录后直接用 `search/show/read` 验证，必要时运行 `node scripts/check.mjs` 检查文档链接。
- CLI 不自动构建；源清单或文档变化后，需要生成物一致时再执行原有的 `node scripts/build.mjs --final --release`。

## 资料边界

- 组件 ID、名称、模块、依赖以 `src/manifests` 和构建生成的 `registry.json` 为准；registry 不手改。
- API 参数、默认值、调用上下文和限制由[公共编排层](公共编排层.md)、模块文档与当前源码维护；本文件只负责定位、用途和关联。
- 设计原则见[设计共识](设计共识.md)；具体作品中的教学重点、表达与观察顺序由作者判断。

## 设计基础

### Q01 共享观看基础与设计值

- 类型／关联：设计基础；I01 `HNV Tokens`，并关联 C01。
- 检索词：设计值、字号、间距、配色变量、阅读密度、design tokens、readable、spacing。
- 用途：统一组件使用的颜色、字号、行高、间距等候选值，并允许在宿主范围覆盖。
- 适用与边界：适合协调一篇笔记的视觉基础；当前不是可自动选择的多主题系统，也不冻结页面尺寸、动画时间或步数。
- 关联：Q02 排版、Q03 网格；知识重点与主题选择仍由作者判断。
- 后续读取：[I01](core.md#I01)、[设计共识](设计共识.md)、[设计值源码](../src/core/tokens.css)。

## 普通组件

### Q02 标题与正文排版

- 类型／关联：组件；C01 `NoteUI.Typography`。
- 检索词：标题、正文、引导语、辅助说明、文字层级、typography、body text。
- 用途：通过语义标签和作用域样式组织文字层级，可独立挂载，也可直接采用静态样式类。
- 适用与边界：调整文字表现；章节外部间距由宿主或布局组件安排，字符串不按 HTML 解析。必要解释不能仅因名为“辅助说明”就缩到难以发现。
- 关联：Q01 设计基础、Q14 演示舞台。
- 后续读取：[C01](ui-content.md#C01)、[独立示例](../examples/run.html?id=C01)、[内容组件源码](../src/ui/content.js)。

### Q03 响应式区域网格

- 类型／关联：组件；L04 `NoteUI.Grid`。
- 检索词：分栏、网格、跨列、区域布局、grid、responsive layout。
- 用途：按可用容器空间组织列、间距和跨列，是宿主和配方的布局材料。
- 适用与边界：适合安排局部区域；不决定知识阅读顺序，不自动保证不同演示停点的高度稳定。
- 关联：Q16 作者配方、Q17 默认公共舞台。
- 后续读取：[L04](ui-layout.md#L04)、[独立示例](../examples/run.html?id=L04)、[布局源码](../src/ui/layout.js)。

### Q04 公式排版

- 类型／关联：组件；C09 `NoteUI.Math`。
- 检索词：公式、TeX、LaTeX、行内数学、块级公式、math、equation。
- 用途：以本地 KaTeX 渲染宿主给出的完整 TeX，出错时显示原因和原始输入。
- 适用与边界：适合呈现公式；不进行代数推导、计算或公式对象自动配对。分项变化可进一步查看 Q06。
- 关联：Q06 表达式项；使用构建后的 ui-content 可获得已内嵌的本地脚本与字体资源。
- 后续读取：[C09](ui-content.md#C09)、[独立示例](../examples/run.html?id=C09)、[内容组件源码](../src/ui/content.js)。

### Q05 指标与结果读数

- 类型／关联：组件；C12 `NoteUI.Metric`。
- 检索词：数值、单位、指标、结果读数、累计值、metric、readout。
- 用途：组合宿主提供的标签、数值、单位和必要解释，以稳定数字排版支持更新。
- 适用与边界：适合局部数据读数；不计算结果或推断趋势，也不承担解释当前整步的字幕职责。
- 关联：Q07 参数输入、Q17 公共舞台；数值与解释是否需要协调变化由作者决定。
- 后续读取：[C12](ui-content.md#C12)、[独立示例](../examples/run.html?id=C12)、[内容组件源码](../src/ui/content.js)。

### Q06 有身份的表达式项

- 类型／关联：组件；C13 `NoteUI.Expression`。
- 场景支持：mode=layout|cut；默认=layout；说明=expression Adapter 支持 layout/cut，默认 layout。
- 检索词：算式、表达式、逐项相加、公式项、expression、term、stable id。
- 用途：以稳定 ID 组织文本项和完整 TeX 项，提供项级或整体内容区域目标，便于公共层协调变化。
- 适用与边界：适合作者明确知道哪些项保留、出现或换值的表达式；不解析公式含义或自动生成推导。组件负责呈现，过渡由公共层 Adapter 提供。
- 关联：Q04 公式、Q19 聚焦交接；整体观察可查询 `{part:'body'}`，不能一律只框未来结果项。
- 后续读取：[C13](ui-content.md#C13)、[Expression Adapter](../src/demo/adapters/expression.js)、[组件源码](../src/ui/expression.js)、[作者示例](../examples/authoring/index.html)。

### Q07 参数滑块

- 类型／关联：组件；F10 `NoteUI.Slider`。
- 检索词：参数、滑块、区间、步长、刻度、分段映射、ticks、segments、slider、range input。
- 用途：让读者选择宿主定义范围内的单值或区间，提供数值及键盘操作；可选视觉刻度和显式分段映射，默认保持线性真实值域。
- 适用与边界：适合参数联动；物理或数学关系由宿主计算。区间使用两个原生滑块；可选 `ticks` 刻度与显式 `segments` 分段映射，默认仍为线性真实值域，不内置课程阈值或隐式比例。
- 关联：Q05 读数；连续拖动与离散步进是不同交互，不默认把每次数值输入都变成一次完整演示。
- 后续读取：[F10](ui-forms-advanced.md#F10)、[独立示例](../examples/run.html?id=F10)、[组件源码](../src/ui/slider.js)。

### Q08 序列与位串

- 类型／关联：组件；D01 `NoteViz.Sequence`。
- 场景支持：mode=layout|cut|reveal；默认=layout；说明=sequence Adapter 默认 layout，支持 cut/reveal。
- 公共接入：sequence Adapter；sceneModes `layout`/`cut`/`reveal`；独立调用用 NoteViz.Sequence，scene 用 binding adapter `sequence`。入口：[Adapter 视图与目标](公共编排层.md#5-1-内置-adapter-的视图与目标)、[sequence Adapter](../src/demo/adapters/sequence.js)。
- 资源：api=docs/viz-objects.md#D01；source=src/viz/objects-sequence-matrix.js；example=examples/run.html?id=D01
- 检索词：序列、比特串、字节、顺序对象、sequence、bits、bytes。
- 用途：排列带稳定 ID 的位、字节和盒子对象，显示分组、当前关注和本步变化。
- 适用与边界：独立组件更新直接呈现状态；过程动效需公共层接入或具体机制。等宽单元不适合表示真实字段长度比例。
- 关联：Q13 插入机制、Q15 字段组合块；独立分组参数与 scene Adapter 分组约定分别查阅，不能混用。
- 后续读取：[D01](viz-objects.md#D01)、[Sequence Adapter](../src/demo/adapters/sequence.js)、[独立示例](../examples/run.html?id=D01)。

### Q09 矩阵与网格数据

- 类型／关联：组件；D02 `NoteViz.Matrix`。
- 场景支持：mode=cut|update；默认=update；说明=matrix Adapter 仅支持 cut/update，默认 update；不支持 layout/reveal 与行列重排。
- 检索词：矩阵、行列、单元格、二维数据、matrix、row、column、cell。
- 用途：呈现有行列标签的数据，以公开目标查询和 cues 支持行、列及单元关注与变化。
- 适用与边界：数值和计算由宿主提供；当前公共接入支持 cut/update，不能据此推断已有行列重排或转置布局动画。
- 关联：Q06 表达式、Q19 聚焦交接；关注表示当前使用的对象，changed 表示发生变化，二者不混用。
- 后续读取：[D02](viz-objects.md#D02)、[Matrix Adapter](../src/demo/adapters/matrix.js)、[作者示例](../examples/authoring/index.html)。

### Q10 当前关注与框选

- 类型／关联：组件；R07 `NoteExpr.Focus`。
- 检索词：焦点框、框选、注意力、下划线、focus、highlight、attention。
- 用途：框选真实元素或标记文本范围，并在目标之间迁移；公共舞台可用它承接连续观察位置。
- 适用与边界：独立使用是 show/hide/refresh，不是统一 update；视觉标记不替代正文解释。目标要有可用几何，隐藏或消失对象不能假定为有效观察目标。
- 关联：Q19 聚焦与内容交接；独立标记能力不等于已经协调内容启动。
- 后续读取：[R07](legacy.md#R07)、[Focus 源码](../src/expr/focus.js)、[公共层 API](公共编排层.md)。

### Q11 范围括线与就近说明

- 类型／关联：组件；R08 `NoteExpr.Range`。
- 检索词：范围、括线、分组说明、区间批注、range、bracket、annotation。
- 用途：在一组真实对象外侧绘制括线及说明，表达“这些对象共同属于这一说明”。
- 适用与边界：只提供视觉标记；不生成数据分组或推断字段语义，不宣称解决任意多层标注和复杂避让。
- 关联：Q08 序列；与 Q19 的 union 观察区域不同，后者合并的是焦点测量范围。
- 后续读取：[R08](legacy.md#R08)、[独立示例](../examples/run.html?id=R08)、[Range 源码](../src/expr/range.js)。

### Q12 对象关系连线

- 类型／关联：组件；R09 `NoteExpr.Link`。
- 检索词：对应关系、连线、箭头、映射、link、connector、mapping。
- 用途：连接两个对象锚点，配合方向和关系文字表达局部关系。
- 适用与边界：关系含义由宿主给出；不是完整关系图引擎，也不由连线推断因果、计算或教学顺序。
- 关联：Q10 关注、Q11 范围；整张节点图应进一步查看 D03，不能靠大量局部连线冒充自动布局。
- 后续读取：[R09](legacy.md#R09)、[独立示例](../examples/run.html?id=R09)、[Link 源码](../src/expr/link.js)。

### Q13 序列插入与让位

- 类型／关联：机制组件；R10 `SeqInsert`。
- 检索词：插入、让位、撤回、序列扩张、insert、shift、restore。
- 用途：展示单一插入点的新对象落位与既有对象让位，并支持恢复、重看和换内容。
- 适用与边界：已测原序列 1–5 项、单插入点；不扩大解释为任意长列表、多处编辑或多行插入。旧接口是 insert/restore/replay/setData 等，保留 keepState 的实际语义。
- 关联：Q08 序列状态容器；两者不能仅因都显示序列就视为同一接口。
- 后续读取：[R10](legacy.md#R10)、[独立示例](../examples/run.html?id=R10)、[插入 Adapter](../src/demo/adapters/sequence-insert.js)。
